# Open questions

The agent adds questions after reading `concept.md`. `[ ]` = unanswered,
`[x]` = answered (the answer goes right under it, with the date).

- [ ] What is stchat, and who is it for? (see concept.md)
- [ ] Which tech stack? (default suggestion once the concept is clear)
- [ ] Where will the code live (GitHub repo name, default branch)?
- [ ] Where will it run in production, and what's the domain?
- [ ] Which mail path should status and deployment emails use?
