Handshake: how to use it

Met someone? Keep talking without swapping numbers. This guide walks through every screen of the working prototype, using real screenshots from a phone-sized browser.

1. Getting started

Open the Handshake web page on your phone. There's nothing to install and no sign-up: no email, no phone number. Tick that you're 18 or older, then tap Get my code.

Next, say where you are. Codes only work between people in the same place, so there are three ways to do it:

  • Scan the table tent. At a venue, point your phone camera at the QR code on the Handshake table tent or poster.
  • Type the zone and table words. The tent shows a zone number (like 47) and two short words (like maple fox) that change every Monday.
  • Use my area. Anywhere else, your phone rounds your location to a square about 1 km wide before sending it. Handshake turns that into a zone number and forgets it.

2. Your code

Your screen shows a code made of three pairs of digits, like 12-34-49. The first pair (in orange) is the zone. The ring counts down from 60 seconds, then you get a fresh code automatically. Each code works once.

In a loud room, tap Show big to fill the screen with your code so the other person can read it.

3. Connecting with someone

  1. Say your codes to each other out loud.
  2. Type their code into Their code and tap Connect. You'll see "Got it! Now they enter your code."
  3. When they type yours, a private chat opens on both phones at once.

It always takes both of you. Nobody can start a chat with you on their own. A typo doesn't use up anyone's code; just try again.

Someone overheard your code? If a second person types it, Handshake cancels it, gives you a new one and tells you: "Two people entered your code, so we made you a fresh one." Nobody gets connected by accident.

4. Chatting

You each get a random nickname for this chat only, like Rosy Finch, so nobody can link you across chats. Messages arrive instantly. Every chat vanishes after 14 days unless everyone taps Extend 14 days.

The Menu holds everything else: People and reveals, Add someone, Group handshake, Extend, Report a problem, and End chat (or Leave group).

5. Sharing more, one person at a time

Everyone starts anonymous. If you'd like to share more, fill in Me (all optional): first name and photo, social handles, phone number. Nothing there is shown to anyone yet.

Then open Menu → People and reveals. There are three steps: 1. First name and photo, 2. Social handles, 3. Phone number. A step opens only when you both tap Share on it. Steps go in order, and you can tap Stop any time.

In a group it's still one person at a time. Sharing with one member never shows your details to anyone else.

6. Adding someone to a chat

A chat can grow to 8 people, but only if the group agrees.

  1. In the chat, tap Menu → Add someone. You get a one-time code for this chat.
  2. The newcomer types that code on their phone, and you type their code, the same two-way handshake as before. Tap Ask the group.
  3. Everyone already in the chat sees "Someone new wants to join" with Yes and Not this time. By default everyone must say yes. Nobody sees how anyone else voted.
  4. Once approved, the newcomer is in. They see only messages sent after they joined, and nobody's name or details.

Each chat can choose who must agree: Everyone agrees (the default), Most people agree or Any one member. Find this at the bottom of People and reveals. A stricter choice applies at once; a looser one needs everyone to pick it. The same rule applies when someone asks the group to remove a member. Requests that nobody answers expire after 10 minutes.

7. Group handshake

All together in person? Instead of adding people one by one, tap Menu → Group handshake. Anyone nearby can type the code shown for the next 2 minutes. Each person who does still needs the group's yes, including from you, since you didn't vet them one by one.

8. Leaving and ending

End chat for both of us (in a one-to-one) makes the chat disappear for both people. There's no "blocked" message, just "This chat has ended." Leave group removes only you. If fewer than 2 people remain, the chat disappears. You can also delete everything about your device from Me → Delete everything about me.

9. Staying safe: reporting

Menu → Report a problem. Choose a reason, and add a note if you like. You can tick a box to attach the last 20 messages so the team can see what happened. It's off unless you tick it. After reporting you can quietly leave; nobody is told you reported them. The team can stop a device from starting or joining chats.

10. Demo mode: try it alone

For sales demos and pilot onboarding, demo mode adds a friendly bot. On your code screen tap Try with a demo friend. The bot has already typed your code, so type its code and you're connected. It replies to messages, matches your reveal steps, and says yes to join requests. Inside a chat, the menu also offers Demo: a newcomer asks to join so you can try approvals. Demo mode is on in development and off in production unless DEMO_MODE=true.

11. For venues

Each venue gets a private staff link (the Handshake team creates it in admin). It opens three pages:

  • Table tent: print it and put it on tables. It shows the zone number, a QR code, this week's two table words, and three-step instructions. The QR code and words change every Monday; last week's keep working until Monday noon.
  • Live display: the same tent for a tablet or screen. It refreshes itself and shows themed windows such as "Thursday trivia night".
  • Dashboard: how many new connections and group additions happened each day. Counts only; never who, what or exactly when. Days with 1–2 show "fewer than 3".

Venue zones only work during opening hours. A posted code is no use from home: you need this week's QR code or table words, and a chat still needs both people to type each other's code.

12. For the Handshake team (admin)

Admin lives at /admin and is switched off unless an admin password is set. Reports shows each report's reason, note, nickname, and the messages only if the reporter attached them. From there you can resolve a report or suspend a device. Venues creates a venue and shows its staff link once. Metrics shows daily totals only (handshakes, chats, groups, second-day conversations, reveal steps), which are the numbers the pilot's go/no-go decision uses.

13. Privacy in plain words

  • We never store location history, sell data or run ads.
  • "Use my area" sends only a rounded square about 1 km wide, which is turned into a zone number and forgotten.
  • Codes are stored scrambled and deleted within about two minutes.
  • Logs never contain codes, messages, zones or internet addresses.
  • Messages are encrypted in the database and deleted with the chat. They are not end-to-end encrypted: the server can read them in order to deliver them, and we say so.
  • Encrypted backups are kept up to 7 days.

14. Running it yourself

The app is in the handshake/ folder of the package. On a Mac with Ruby 4.0.10 and PostgreSQL:

  1. cd handshake then bin/setup (installs everything, prepares the database, starts the server).
  2. bin/rails db:seed adds a cafe, a climbing gym, a bar and a conference. It prints each zone's table words.
  3. Open http://localhost:3000 in two different browsers (or one private window), choose zone 12 with its table words, and swap codes. Or use demo mode with one browser.
  4. Staff pages in development: /dash/dev-conf, /dash/dev-bean. Admin: start the server with ADMIN_PASSWORD=… (12+ characters).

Deploying (Kamal on your own server, or Render) is described step by step in handshake/README.md. Nothing has been deployed; that waits for your go-ahead.
